# turtle_motion 功能包：小海龟自主绘制正方形

## 一、任务描述

这次作业的目标是让 ROS 里的小海龟自己走一个正方形。小海龟是 turtlesim 仿真里的一只乌龟，它自己没有脑子，全靠我们给它发速度指令才能动。

画正方形的方法很简单：先直着往前走一段距离，停下来，然后向左转 90 度，再往前走一段，停下来，再左转……这样重复 4 次，走完 4 条边就回到起点，轨迹正好是一个闭合的正方形。

## 二、实现思路

小海龟的运动用的是 ROS 的话题通信。turtlesim 里有一个叫 /turtle1/cmd_vel 的话题，小海龟会一直订阅它。我们只要往这个话题上发布 Twist 类型的消息，小海龟就会按照消息里写的速度来运动。

Twist 消息里主要用到两个量：

- linear.x：线速度，控制海龟前进快慢（单位 m/s）
- angular.z：角速度，控制海龟转头快慢（单位 rad/s），取正值是逆时针转

这里用的是**时间开环控制**，就是不去管海龟实际走到哪了，直接用公式把时间算好：

- 直走：t = s / v，比如速度 1 m/s、边长 2 m，那走 2 秒停下来就行
- 转弯：90 度 = π/2 弧度，t = 角度 / 角速度

每次动作结束后都发一个速度为 0 的消息让海龟停下来，不然它会因为惯性滑过头，画出来的角就不是直角了。

## 三、代码实现

功能包叫 turtle_motion，目录结构如下：

```
turtle_motion/
├── package.xml        # 包的说明文件，声明了依赖 rospy 和 geometry_msgs
├── CMakeLists.txt     # 编译配置，负责把脚本装到 bin 目录
└── scripts/
    └── square_draw.py # 主程序，画正方形的节点
```

主程序是一个叫 turtle_square_node 的节点，主要流程：

1. 初始化节点，创建发布者，往 /turtle1/cmd_vel 发消息
2. 写了两个函数：move_forward() 负责直走，rotate_90_degrees() 负责左转 90 度
3. 主循环跑 4 次：直走 -> 停 0.5 秒 -> 左转 -> 停 0.5 秒
4. 循环里和最后都用 rospy.is_shutdown()、try-except 做了保护，节点被 Ctrl+C 关掉时海龟也能停下来

## 四、运行方法

先启动 roscore 和小海龟仿真，再运行画正方形的节点，一共三步：

1. roscore
2. rosrun turtlesim turtlesim_node
3. rosrun turtle_motion square_draw.py

## 五、结果总结

程序运行后，可以在 turtlesim 窗口里看到小海龟沿着正方形走了一圈，最后回到起点，画出一个边长 2 m 的正方形。

通过这次作业，我学会了 ROS 话题通信的基本用法（发布者向 /turtle1/cmd_vel 发布 Twist 消息），也理解了时间开环控制的思想：用 t = s / v 这样的公式算好运动时间，到点就停。
